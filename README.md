# 🚀 SpaceQuest

A 2D arcade-style space survival game built using Unity.  
Fight against waves of enemies, dodge obstacles, and survive as long as possible.

---

## 🎮 Gameplay Features

- 👾 Wave-based enemy spawning system
- ⚡ Player boost mechanics
- 💥 Object pooling for optimized performance
- 🔫 Shooting system with sound effects
- 💀 Collision and destruction system
- 🎯 Score-based survival gameplay

---

## 🛠️ Built With

- Unity (2D)
- C#
- Object-Oriented Programming (OOP)
- Unity Physics System
- Custom Object Pooling System
